# Caravan Survival v0.11.0

Region 1 playable end to end: five Whispering Woods towns, generated roads with faction walls and roaming wildlife, the full party system and the new town screens.

## What's in this version

- **Trade loop** between five towns (Oakhaven, Deepwood, Mossmere, Greywatch, Thornfield) with per-town prices, weekly stock and a destination choice when you set out.
- **Roads:** the hand-made starter road plus generated roads mixing **sentient armies** (Wood-Rot Goblin scrap walls with scouts, Bleak-Iron shield-walls with crossbowmen and a charging Deserter Captain) and **roaming wildlife** (dire wolves, bog bogles, needle-gnats). Enemy tiers keep the first roads gentle.
- **Party:** four classes (Footman, Crossbowman, Arcanist, Rogue), named guards with XP, morale and wages, level 6 paths, the Ice school, backpacks with salvage, hiring in the Mercenary Guild and rare buildings.
- **Town:** the pixel-art town square with building buttons, and the town menu with cards, the cart grid and the storage tray.
- **Combat:** postures, three formations, four active skills, the iron gate ambush, the road camp.

## Downloads

- **Android:** `CaravanSurvival-v0.11.0-android.apk` (debug-signed; allow installs from unknown sources).
- **Windows:** `CaravanSurvival-v0.11.0-windows.zip` (unzip and run `CaravanSurvival.exe`; unsigned, so SmartScreen warns once).
- **Web:** `CaravanSurvival-v0.11.0-web.zip` (serve the folder with any web server), or the hosted build on GitHub Pages once enabled.

## Known gaps

- One region only (by design for the first full version).
- No world map screen yet; destinations are chosen from a list.
- No cart upgrades, road events or roguelite mode yet.
