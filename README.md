Whispering Woods, trade between towns, hire and grow your guards, and fight
past goblin walls and dire wolves on the road.

Every version is listed here with its downloads. The links work without a
GitHub account. New versions are added when they are released.

## How to install

- **Android:** download the APK on your phone and open it. Android asks once
  to allow installing apps from your browser; allow it. The build is
  debug-signed (not from the Play Store). Play in landscape.
- **Windows PC:** download the zip, extract it and run `CaravanSurvival.exe`.
  It isn't code-signed yet, so SmartScreen warns the first time: choose
  "More info", then "Run anyway".
- **Web on Netlify:** download the Netlify zip. In Netlify, open your site's
  **Deploys** page and drag the zip onto the "drag and drop" area (or unzip
  it and drop the folder on app.netlify.com/drop). `index.html` is at the
  top of the zip and a `_headers` file is included, so it runs as-is. The
  same files work on any static web host.
